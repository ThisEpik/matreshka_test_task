# matreshka_test_task

Данные как и требовалось использовал фейковые, по чистой архитектуре создал интерфейсы репозитория, и модели данных, их же использовал в UI. Все интерфейсы лежат в domain папке.

По поводу ИИ, хотя я и был скептично настроен по поводу агентов, но сейчас сильно задумался об их использовании. А по тестовому я активно использовал chatGPT чтобы "гуглить", и генерить анимации: PageView для тасков, AnimatedSwitcher для премиум блока, и полоску опыта мне тоже нарисовал ИИ.

Весь UI и элементы писал сам, кроме полоски опыта. У меня получилось добиться адаптивности не подгоняя размеры свои под нужды, при этом сохраняя пропорции.

Большую часть времени заняло придумывание как всё адаптировать к макету и работу с фигмой(поиск ассетов(некоторые из них пришлось править руками), работа с constraints, подгонка UI, постоянная сверка, скачивание ассетов(они все качаются в архиве, который имеет одно имя)). Но под конец когда я подготовил почву для адаптивности работа шла куда плавнее.

В этом тестовом можно сделать куда больше, добавить локализаци, вынести хардкод строки в json, обработать потенциальные ошибки сети, добавить useCase и т.д. Но я сконцентрировался именно на верстке.

В целом по ТЗ, хочу сказать что хочу продолжить в этом направлении, и со временем стану куда быстрее выполнять подобные задачи.
